# Sevenfall website and documentation

The GitHub Pages site describes the five-faction, twenty-subfaction skirmish alpha. It publishes from `docs/` through `.github/workflows/pages.yml` on `main`; no separate website platform or secret token is required in the site.

Public site: [Sevenfall](https://mrkrissatan.github.io/Sevenfall/).

| Page | Content / source |
|---|---|
| `index.html` | Five faction emblems, linked subfactions, gameplay overview, release downloads and live GitHub issues |
| `forces.html` | 181 illustrated entries; generated by `scripts/build_site_catalogue.py` from rules and artwork manifests |
| `subfactions.html` | Twenty playstyles, counters, forty exclusive units and power details; `scripts/build_site_subfactions.py` |
| `new-realms.html` | Noetic/Forsaken doctrines and painted shared roster; `scripts/build_new_realms_page.py` |
| `arsenal.html` | Five shared aircraft, beasts and powers; `scripts/build_realm_arsenal_page.py` |
| `turnarounds.html` | 80 current unit entries plus 14 future concepts across all five factions; `scripts/build_turnaround_gallery.py` |
| `campaigns.html` | Six interwoven campaign designs and a spoiler-protected Veilborn finale, explicitly not finished playable content |

Regenerate the catalogue before the playstyle page. To export new integrated direction previews, install Pillow and run `scripts/prepare_extended_turnarounds.py`, then rebuild the gallery. Existing previews remain committed so normal site publication needs no image dependency. Update the templates/generators as well as generated HTML. Run the website/roster tests before publishing.

The live issues and release history use the public read-only GitHub REST API. Static fallbacks remain readable if fetching is blocked. No credentials are embedded. Historical release reports remain dated; [FACTIONS.md](FACTIONS.md), [TESTER_GUIDE.md](TESTER_GUIDE.md) and [TESTER_ALPHA_ACCEPTANCE.md](TESTER_ALPHA_ACCEPTANCE.md) describe current gameplay and testing.
