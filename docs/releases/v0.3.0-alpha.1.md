# Sevenfall 0.3.0-alpha.1 — Windows skirmish tester release

A complete standalone **Windows x64 skirmish alpha** for testers. OpenRA, Red Alert
and a separately installed .NET runtime are not required. This is an early alpha,
not the finished campaign game.

## Download and play

- **Setup EXE:** install for your Windows account, then launch Sevenfall.
- **Portable ZIP:** extract the whole folder to a writable location and run `Sevenfall.exe`.
- **Project source ZIP:** Sevenfall plus pinned OpenRA/SDK source and reviewed engine overlay.
- **Dependency source ZIP:** corresponding native/audio library and font sources, notices and build/relink instructions.
- SHA-256 checksums accompany all four downloads.

Choose **Singleplayer → Skirmish**. Pick a faction, add Sevenfall AI opponents and
select a map. The Twelvefold Scar supports up to twelve players. Select your MCV
and press **F** to deploy. Build power, a Veilworks refinery, barracks and vehicle
production. [Tester guide](https://github.com/MrKrisSatan/Sevenfall/blob/v0.3.0-alpha.1/docs/TESTER_GUIDE.md).

## Included

- Twelve faction choices across Angels, Humans and Hell, including Choir of
  Desolation, Area Fifty Two and Circle of Contempt.
- Original units/buildings, animation and damage states, faction defenses and HUDs.
- Physical Veilglass harvesting, hazardous deposits, garrisonable houses and repairable bridges.
- Broken Choir, Ashen Crossing and the new 256×256 Twelvefold Scar, with original
  impassable cliff terraces, villages, forests and contested expansion resources.
- Self-contained .NET 10.0.13, per-user setup, portable game and dedicated server.

## Verification

The source pass ran 98 Python tests and 120 C# assertions. Native checks cover
cliff movement and twelve starting positions, real map-cache thumbnails, doctrine
mechanics, completed autonomous conquest and finalized replay playback. Two
independent clients passed doctrine checks with matching simulation hashes;
save/load matched uninterrupted world state at four checkpoints. The Windows
release workflow repeats package/native/multiplayer/save-load checks on a fresh
runner, then verifies install/reinstall/uninstall and user-data preservation.

The release records exact source revisions and engine patch hashes in
`BUILD_INFO.json`, file hashes in `FILES.sha256.json`, and distribution notices in
`Notices`. All 16 runtime packages have notice coverage; 21 source components and
the exact corresponding GNU FreeFont source are supplied.
[Acceptance details](https://github.com/MrKrisSatan/Sevenfall/blob/v0.3.0-alpha.1/docs/TESTER_ALPHA_ACCEPTANCE.md).

## Known alpha scope

Land skirmishes only. Campaign previews and aircraft/naval/beast production are
excluded. Music and voice coverage remain limited; presentation, balance, larger
armies, more GPUs and Internet/NAT/latency conditions need tester feedback.
Cliff elevation is visual and blocks ground movement; it grants no height-based
range, sight or damage bonus. Executables are unsigned. Cross-version save/replay
compatibility is not promised. After loading a game, use Resume in the options menu.

Settings, saves, replays and logs are in `Support`. Reinstall and uninstall preserve
user data. Please report the exact version, map, faction and reproduction steps at
[GitHub Issues](https://github.com/MrKrisSatan/Sevenfall/issues), with a relevant replay
or inspected log when possible.
